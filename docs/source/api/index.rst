API Reference
=============

The API Reference is generated from the Python modules under ``src/pwrs``.
It includes all source modules and their public functions, classes, and
methods. Members whose names begin with an underscore are intentionally
omitted from the reference.

The data page lists the bundled MATPOWER and PGLib-OPF cases. The module
index contains the complete source-level reference grouped by package.
